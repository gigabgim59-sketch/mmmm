# 프레드릭 제임슨 · 네 권의 서재

네 권의 한국어 번역과 원전 PDF를 모은 정적 HTML 서재입니다. 모바일 화면에 맞춰 읽기, 글자 크기 조절, 검색, 밑줄과 메모를 사용할 수 있습니다.

## 서재 열기

[서재 HTML 파일](index.html)을 내려받아 브라우저에서 열 수 있습니다. 원전 및 번역 PDF 버튼까지 사용하려면 저장소 전체를 같은 폴더 구조로 내려받거나 GitHub Pages로 게시해야 합니다. GitHub의 파일 보기 화면 자체는 HTML을 실행하지 않습니다.

현재 저장소의 비공개 설정은 유지합니다. GitHub Pages를 이용하려면 [Pages 설정](https://github.com/gigabgim59-sketch/mmmm/settings/pages)에서 계정 요금제의 비공개 저장소 지원 여부와 게시 설정을 확인하세요. 사이트가 게시되면 주소는 `https://gigabgim59-sketch.github.io/mmmm/`입니다.

## 현재 번역 범위와 원문 대조

『리얼리즘의 이율배반』은 제공된 서론과 제1부 제1~6장, 각주 157개만 수록했습니다. 책 표지와 읽기 버튼을 다른 세 권과 같은 형식으로 맞췄습니다.

이 책의 문단별 원문 대조는 번역 완성 후 추가 예정입니다. 현재 원문 버튼과 쪽 번호는 원전 PDF로 이동하며 OCR은 사용하지 않았습니다. 원전은 두 쪽씩 묶인 스캔본이며, 페이지 내용 손실 없이 세 PDF로 나눠 올렸습니다. 원전 버튼은 해당 파일과 펼침면으로 이동합니다. 1번 파일은 원본 PDF 1~60쪽, 2번은 61~120쪽, 3번은 121~172쪽입니다. 쪽 번호가 없는 인용문은 이웃 문단의 쪽 번호를 기준으로 이동합니다.

다른 세 권의 기존 문단별 원문 대조는 유지됩니다. 『변증법의 원자가』 역시 기존 부분 번역입니다. 밑줄·메모와 읽던 위치는 사용하는 브라우저에 저장됩니다.

`index.html`, `orig/`, `pdf/`를 같은 위치 관계로 유지하세요. `translations/`에는 책별 독립 HTML도 들어 있습니다. 별도 빌드는 필요 없습니다.
