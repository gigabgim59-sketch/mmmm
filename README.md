## 완성본과 원문 대조

『리얼리즘의 이율배반』은 2026년 11월 4일 제공된 완성본으로 갱신했습니다. 서론, 제1부 9장, 제2부 3장, 색인, 각주 336개와 도표를 모두 수록했습니다. 책 표지와 읽기 버튼을 다른 세 권과 같은 형식으로 맞췄습니다.

제공된 [전권 작업용 OCR](sources/ar-ocr-working.md)을 연결했습니다. 원서 1–26쪽은 문단 식별자로 연결한 원문이며, 27–326쪽은 번역문에 기록된 쪽 번호에 따라 해당 쪽 전체의 OCR을 표시합니다. 쪽 단위 OCR은 정밀 문단 대조가 아니며 오인식·문단 경계 오류가 남을 수 있습니다. 원문 대조 버튼과 영어 검색을 사용할 수 있고, 쪽 번호에서 원전 PDF도 확인할 수 있습니다. 원전은 두 쪽씩 묶인 스캔본이며, 페이지 내용 손실 없이 세 PDF로 나눠 올렸습니다. 원전 버튼은 해당 파일과 펼침면으로 이동합니다. 1번 파일은 원본 PDF 1~60쪽, 2번은 61~120쪽, 3번은 121~172쪽입니다. 쪽 번호가 없는 인용문은 이웃 문단의 쪽 번호를 기준으로 이동합니다.

다른 세 권의 기존 문단별 원문 대조는 유지됩니다. 『변증법의 원자가』 역시 기존 부분 번역입니다. 밑줄·메모와 읽던 위치는 사용하는 브라우저에 저장됩니다.

`index.html`, `orig/`, `pdf/`를 같은 위치 관계로 유지하세요. `translations/`에는 책별 독립 HTML도 들어 있습니다. 별도 빌드는 필요 없습니다.
